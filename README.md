# Lab Report Writer

## 简介📌

一个用于 Codex 的实验报告写作 skill。

可以生成：

- 实验指南 （详细的步骤 告诉你实验在做什么 & 如何完成实验）
- 预习报告 （无实验结果分析及后面的部分）
- 完整实验报告

建议提供：

- 实验指导书 / PPT
- 实验报告模板
- 实验结果图片或数据
- 实验报告示例（可选）

## 如何使用🚀

这是一个 Codex skill。先建立项目文件夹，将实验相关文件全部放入，再在 Codex 中选择项目，选择“打开已有文件夹”。

**请务必说明这次做的是实验几，需求是实验指南/预习报告/完整实验报告。**
为了避免因为文件命名不同，让 Agent 花很多时间搜索和判断，建议指出哪些文件是实验指导书、实验模板、参考报告或实验结果。

### 生成实验指南

```text
请用 /lab-report-writer 来帮我写实验指南。我做的是实验一，xxxx.pdf 是实验指导书。
```

### 生成预习报告

```text
请用 /lab-report-writer 来帮我写预习报告。我做的是实验一，xxxx.pdf 是实验指导书，xxxx.docx 是实验模板，xxxx.pdf 是参考实验报告。
```

### 生成完整实验报告

```text
请用 /lab-report-writer 来帮我写实验报告。我做的是实验一，xxxx.pdf 是实验指导书，xxxx.docx 是实验模板，xxxx.pdf 是参考实验报告，xxxx.png 是实验结果。
```

## LaTeX 说明🧩

Agent 生成 LaTeX 文件后，可以在 VS Code 中打开，用 LaTeX Workshop 插件编译。
注意：电脑上需要先安装 LaTeX 编译器，例如 TeX Live、MiKTeX 或 MacTeX。

默认情况下，报告会使用 LaTeX 常见的 `1.1`、`1.2` 这类章节格式。也可以明确要求完全按照模板生成 `一、`、`1.`、`（1）` 这样的分点格式。
